Integrated automated test execution with Jenkins and GitHub Actions for CI/CD workflows.
Organized automation components to improve test reusability, maintainability, and execution.
Technology Stack: Python, Playwright, Selenium WebDriver, Pytest, Robot Framework, Selenium Library, Gherkin, BDD, Requests, POM, Jenkins, Git, GitHub Actions.
